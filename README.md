🛒 Smart Product Explorer

📌 Overview

Smart Product Explorer is a web-based application designed to provide an interactive product discovery experience similar to modern e-commerce platforms. The application allows users to browse, search, filter, and sort products dynamically using real-time data fetched from a public API.

The platform focuses on efficient data handling and responsive UI design to simulate a real-world shopping interface.

⸻

🎯 Purpose

The purpose of this project is to:
	•	Build a dynamic web application using API integration
	•	Implement search, filtering, and sorting using JavaScript
	•	Develop a responsive and user-friendly interface
	•	Apply array higher-order functions for data manipulation

⸻

🚀 Core Features

🛍️ Product Listing
	•	Display products in a responsive grid layout
	•	Show product image, title, price, and rating
	•	Dynamic rendering using API data

🔍 Search Functionality
	•	Search products by name
	•	Real-time filtering of results
	•	Implemented using .filter()

🎯 Filtering System
	•	Filter products by category
	•	Filter by price range
	•	Filter by rating

📊 Sorting Options
	•	Sort by price (low to high / high to low)
	•	Sort by rating
	•	Sort alphabetically

❤️ Favorites System
	•	Save and remove products from favorites
	•	Data persisted using localStorage

📦 Product Details
	•	View detailed information about a product
	•	Includes description, price, category, and rating

⸻

🌐 API Used

FakeStore API

Provides:
	•	Product data
	•	Categories
	•	Pricing and ratings

Base URL:
https://fakestoreapi.com

⸻

🛠️ Technologies Used
	•	React.js
	•	JavaScript (ES6+)
	•	HTML5
	•	CSS3

⸻

🧠 Data Handling Logic
	•	Product data is fetched using the Fetch API
	•	Data is stored in component state
	•	Search is implemented using .filter()
	•	Filtering combines multiple conditions dynamically
	•	Sorting is handled using .sort()
	•	Rendering is done using .map()

⸻

📱 Responsiveness

The application is designed to work seamlessly across:
	•	Mobile devices
	•	Tablets
	•	Desktop screens

⸻

🏁 Conclusion

Smart Product Explorer demonstrates the ability to build a scalable, interactive, and data-driven frontend application. It reflects real-world e-commerce patterns by combining structured data handling with an intuitive and responsive user interface.
